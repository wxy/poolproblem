# Owner-command process lifetime E2E

- Scope: `OwnerCommandRecipe.swift` process lifetime plus the existing E2E harness. No app build, unit tests, real pnpm invocation, staging, commits, or publication.
- Command: `sh docs/verification/pnpm-owner-recipe/run.sh` from the repository root on macOS with Xcode command-line tools and an absolute `TMPDIR`.
- Inputs: a temporary HOME/store, existing shell fixture for baseline scenarios, and a compiled C timeout fixture (no shell wrapper for the timeout scenario).
- Existing regression artifact: `timeout-before.log` records the parent-only implementation failing with `child stopped before timeout was reported`. The current developer pass found both the process-group implementation and this artifact already present; it did not recreate that historical run or rewrite the implementation. It extended the E2E first and verified the current implementation.
- Timeout scenario: native wrapper checks that its PGID equals its PID before action, then forks a child which checks inherited group membership, ignores SIGTERM, writes 256 KiB each to stdout/stderr, and appends a heartbeat every 50 ms. Runner timeout is 500 ms. Compare heartbeat at return and after 800 ms; verify a temporary victim scheduled for deletion after 600 ms survives. The harness kills the fixture child on regression failure before asserting.
- Additional scenarios: a successful native command writes 512 KiB and the returned output must contain exactly 65,536 bytes; a wrapper exits after 100 ms while its child continues, and the runner must stop that child before returning, leaving both heartbeat and delayed-deletion victim unchanged over 800 ms.
- Implementation: direct absolute-path `posix_spawn`, argv/env arrays, atomic `POSIX_SPAWN_SETPGROUP` with PGID 0, checked setup calls, nonblocking shared stdout/stderr pipe and 64 KiB retained output. Whole-group SIGKILL precedes leader reaping on both timeout and normal wrapper exit. `waitid(WNOWAIT)` retains the leader PID until group termination. Darwin's zombie-only group can reject a signal; this is accepted only once the group is confirmed absent after reaping.
- Current run: PASS (exit 0), 21 assertions; timeout elapsed 0.5371350049972534 seconds, heartbeat 18 bytes at return and 18 bytes after 800 ms. See `last-run.log`. All deletion inputs are in the task-specific temporary HOME; no real pnpm executable or real user store is used. The runner uses direct executable/argv spawning; the pre-existing baseline fixture is a shell script, while all process-lifetime scenarios use the native C fixture.
- Limits: process groups cover ordinary inherited descendants, including pnpm wrappers. A program deliberately calling setsid/setpgid to escape is outside this mechanism. The E2E observes heartbeat stability for 800 ms, not every possible descendant behavior. Full app build and UI acceptance remain with Director. macOS 26 emits a deprecation warning for `posix_spawn_file_actions_addchdir_np`; retained for deployment compatibility with macOS 14.
